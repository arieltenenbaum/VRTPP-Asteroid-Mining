### 1. Implemented Open Question #1 — Eccentricity-Aware Initialization (`periapsis-init`)

**Cell 21** (`initialize_mass_ratios`) was replaced with a new strategy:

- **TA-grid T_d candidates**: samples departure body at 16 uniform true-anomaly increments (0°, 22.5°, ..., 337.5°) within [0, 14] TU instead of time-uniform steps. For eccentric bodies (FG3 e=0.35, SG10 e=0.42), this clusters candidates near periapsis where Δv changes fastest. For near-circular bodies (Earth e=0.017), behavior is nearly identical to before.
- **Distance-corrected T_t seeds**: for each T_d candidate, computes T_t_ecc = π√(((r_dep + a_j)/2)³) using the actual heliocentric departure distance instead of mean SMA. Adds 4 seeds: {0.5×T_t_hoh, T_t_hoh, T_t_ecc, 2.0×T_t_hoh}.
- **64 evals/pair** (vs 102 previously) — faster, scales better to larger n_r/n_m.
- No eccentricity threshold; all body pairs treated identically.
- L-BFGS-B refinement from best seed is unchanged.

**Cell 22** updated to display which T_t seed type won per pair (hoh/ecc/fast/slow) instead of grid/periapsis labels.

## Key Implementation Details

### Cell 21 T_t seed logic (periapsis-init)
```python
r_dep = np.linalg.norm(body_i.position_at_time(T_d))
a_ecc = (r_dep + body_j.a) / 2.0
T_t_ecc = np.pi * np.sqrt(a_ecc**3)

T_t_seeds = sorted(set([
    max(eps, T_t_hoh * 0.5),
    max(eps, T_t_hoh),
    max(eps, T_t_ecc),
    max(eps, T_t_hoh * 2.0),
]))
```

**Why 4 seeds instead of {1,3,5,...,13} TU:** the 4-seed version is less computationally expensive and scales better to larger n_r/n_m. The 18.4 result is already better than the paper, so the wider grid is not needed.
